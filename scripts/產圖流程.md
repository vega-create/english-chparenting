# 產圖流程（2026-08-11 定版）

站上所有插圖都是這條線生出來的：**aivideospeed 內部 API → 下載 → 切格去背 → 存進 `public/images/`**。

```
寫 prompt（帶風格參考圖）→ POST /api/tasks 建任務 → 按「批量生成待處理」
        ↓
下載結果 → split_*.py 切格＋去背 → 存 public/images/<區塊>/ → 接進頁面
```

---

## 一、平台與帳號

| 項目 | 值 |
|---|---|
| 平台 | <https://aivideospeed.com>（Vega 已登入的 Chrome 分頁裡直接打 API）|
| 模型 | `kie` / `gpt-image-2-text-to-image`（欄位名 `provider` / `model_id`）|
| 專案 | 「冒險英語 部落格改版」`92a0f302-a84f-449e-804d-2475f2c07736`<br>「冒險英語 成就徽章」`a5ea37fe-8d25-4afa-8aee-5959d26394c3` |

**沒有公開 API，但同源 cookie 就能打。** 在已登入的分頁用 `javascript_tool` 執行 fetch 即可。

新開一個專案：

```js
await fetch('/api/projects', { method:'POST', credentials:'include',
  headers:{'Content-Type':'application/json'},
  body: JSON.stringify({ name:'冒險英語 XXX', type:'image', description:'…' }) })
```

## 二、建任務

```js
await fetch('/api/tasks', { method:'POST', credentials:'include',
  headers:{'Content-Type':'application/json'},
  body: JSON.stringify({
    project_id: '<專案 id>',
    name: 'BLOG-HERO',                       // 之後靠這個名字找結果
    provider: 'kie',
    model_id: 'gpt-image-2-text-to-image',
    model_name: 'GPT Image-2',
    aspect_ratio: '1:1',                     // 或 '3:2'
    ref_images: ['https://…/ref.jpg'],       // ⚠️ 真陣列
    extra_params: {},
    prompt: '…',
  }) })
```

> ⚠️ **`ref_images` 一定要傳「真的陣列」。** API 自己會 `JSON.stringify` 一次；
> 傳字串會變成雙重編碼，前端 `refThumbs` 就炸 `refs.forEach is not a function`，
> 整張任務列表變成「載入中…」永遠不出來。從既有任務複製時記得先 `JSON.parse`。

建完是 `pending`，**要按頁面右上角的「批量生成待處理」才會真的送出**。
（試過 `/api/tasks/submit`、`/api/tasks/run` 都回 `Task not found`，沒挖出正確參數，
所以量產時就是：API 批量建任務 → UI 按一次按鈕。）

按鈕常常第一下沒反應，因為表格還在載入 —— **等列表跑出來再按**。

查狀態／拿結果：

```js
const r = await fetch('/api/tasks?project_id=<id>', {credentials:'include'}).then(r=>r.json());
r.tasks.map(t => [t.name, t.status, JSON.parse(t.result_urls||'[]')[0]]);
// status: pending → generating → success
```

刪任務：`DELETE /api/tasks/<task_id>`（**不是** `?id=`）。

## 三、prompt 怎麼寫

### 一定要帶風格參考圖

`ref-blog-style.jpg` 是拿站上四張既有插圖拼成 2×2 傳到 R2 的，
開頭固定寫：

```
@image1 is the art style to match: soft painterly children storybook illustration,
warm saturated colours, rounded friendly shapes, gentle rim light.
```

沒有這句，每批圖的畫風會不一樣，四個頁面拼起來像四個網站。

### 一次生四張：2×2 田字格

省點數也保證同一批風格一致。田字格的 prompt 要把三件事講死：

```
Output ONE square image on a pure white background: four separate <東西> arranged in a
2x2 grid, evenly spaced, each fully inside its own quadrant, not touching each other
or the edges.

Every <東西> is the SAME shape and size: <共同特徵>.

Only the <顏色／圖案> changes:
top-left: …
top-right: …
bottom-left: …
bottom-right: …
```

### 中文字不要交給 AI 畫

**所有中文一律用 HTML 疊上去**，圖只出「空的」版面。
按鈕、木牌、卡片框都要在 prompt 裡寫死：

```
The button faces must be COMPLETELY BLANK — no text, no letters, no numbers,
no icons, no arrows, no decoration of any kind. Text will be added later.
```

英文短字（`Aa`、`ABC`）實測 OK，中文一定糊。

### 要疊字或疊角色的背景圖

寫「留白」：

```
Keep the upper-centre area calm and uncluttered — a sign will be placed over it.
The whole middle band is OPEN — character cut-outs will be placed there.
```

角色**不要讓 AI 畫進背景**，用站上現成的去背 PNG（`public/characters/<name>/`）疊上去，
這樣角色永遠是對的。

### 要 9 宮格拉伸的框與按鈕

```
The frame must be CENTRED and SYMMETRIC, with the SAME border thickness on all four sides.
The inside is COMPLETELY BLANK and flat.
```

四邊等厚才切得出 `border-image`（見 `globals.css` 的 `.ae-btn` / `.ae-frame`）。

## 四、切格與去背

| 腳本 | 用途 |
|---|---|
| `scripts/split_badges.py` | 徽章：2×2 切格＋去背＋置中到正方形畫布 |
| `scripts/split_blog.py` | 書要去背、文章封面只裁 16:9 不去背 |
| `scripts/split_flood.py` | 通用單字圖切格 |
| `scripts/cut_ship.py` | 單張大圖去背（換首頁飛船那種）|

**去背一律用 flood-fill，不要用 rembg。**
只有「連得到畫面邊界的白」才算背景；rembg 會把旗桿、螺旋槳、彩帶這種
細長又離主體有距離的東西當雜訊刪掉（🎉 的彩帶就是這樣不見的）。

核心那幾行：

```python
whiteish = a[..., :3].min(axis=2) > 235
seed = np.zeros_like(whiteish); seed[0,:]=seed[-1,:]=seed[:,0]=seed[:,-1]=True
seed &= whiteish
bg = ndimage.binary_propagation(seed, mask=whiteish)   # 只有連到邊界的白才是背景
```

### 上架前一定要檢查底部

生成圖**很常在最底下留一排雜點或一條整寬的灰槓**（小屋木牌就是這樣，
在網站上看起來像「卡了一條髒髒的線」）。檢查法：

```python
a = np.array(im)[..., 3]
for y in range(h-1, h-40, -1):
    print(y, int((a[y] > 10).sum()))   # 接近整寬的列＝殘留，切掉
```

切掉之後**框的 aspectRatio 與疊字的 top% 都要跟著換算**。

## 五、存去哪、怎麼接

```
public/images/
  ui/        按鈕、卡片框（btn-*.webp / frame-card.webp）
  home/      首頁區塊（pals-band / badge-shelf / parent-photo）
  blog/      圖書館主視覺、分類書、文章封面、書架
  books/     閱讀花園主視覺、四階段圖示、covers/ 書封
  parents/   家長中心主視覺、數字卡圖示、補給站卡片圖
  badges/    ach-*.webp 成就徽章
  tasks/     今日任務的圖示
```

- 一律存 **webp**，`quality=86~92`
- 大圖 `thumbnail((1600,1600))`、圖示 `thumbnail((320,320))`
- **換掉既有圖要在網址加 `?v=N`**，不然瀏覽器會繼續用舊的
  （首頁飛船 `hero-ship-crew.webp?v=4` 就是這樣）

疊在圖上的文字用百分比定位，框要跟圖同比例：

```tsx
<div className="relative w-full mx-auto" style={{ aspectRatio: '1536 / 1024', maxWidth: '640px' }}>
  <img src="…" className="absolute inset-0 w-full h-full object-contain" />
  <h3 className="absolute left-1/2 -translate-x-1/2 top-[4%]">標題</h3>
</div>
```

> ⚠️ **不要同時給 `aspectRatio` 和 `maxHeight`。** 框會變成「全寬 × 限高」，
> 跟圖的比例對不上，用 % 定位的東西就全部飛出去（徽章木架踩過）。
> 要縮小就限 `maxWidth`。

## 六、R2 中轉（要把自產檔案餵給外部平台時）

Chrome 工具擋自產檔案上傳，所以先丟 R2 再讓頁面 fetch 回來：

```bash
npx wrangler r2 object put adventure-audio/tmp/xxx/ref.jpg --file=… --content-type=image/jpeg --remote
```

> ⚠️ **一定要加 `--remote`**，不然只寫到本機模擬器。
> bucket CORS 只開 GET/HEAD 給 app.videoexpress.ai / app.artistly.ai / app.clonevoice.ai
> （設定檔 `scripts/r2-cors.json`）。
