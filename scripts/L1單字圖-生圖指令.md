# L1 單字圖生圖指令（42 張）

2026-08-09。L1 是每個孩子必經的第一關，先只補這一級；L2 以後等有人走到再說。

## 規格

- 存成 `public/words/<slug>.png`，**檔名就是下面每一項的 slug**（小寫、只有英文字母）
- 生成時**背景是深色或白色都沒關係**，我會用 rembg 去背、裁邊、縮成 256×256
- 一次生一張，或多張一起生都可以

## 共用風格（每次都要貼在最前面）

```
Style: glossy 2.5D cartoon game asset, single object centered,
thick clean outline, smooth cel-shaded gradients, soft specular
highlights, subtle inner shadow for depth. Bright, high
saturation, friendly rounded shapes, appealing to children aged
5 to 12. Same rendering style as a premium mobile game icon set.
No text, no letters, no background scenery, no ground shadow.
Square composition, 1024x1024, PNG.
```

就是這個風格，可以拿 `public/words/apple.png` 當參考圖餵給 AI。）*

## 不用生的

- **字母卡**（`A a`、`B b`…共 10 個）：介面已特別處理，顯示字母本身
- **文法詞**（a / an / the / is / it / am / I / you / me / we / to / and）：
  抽象、畫出來反而混淆，維持 emoji fallback
- **片語**（a ball / a sun / an egg / an orange / an igloo / an umbrella / a hat）：
  等上面的 `ball` `sun` `egg` `orange` `igloo` `umbrella` `hat` 生好後，
  我直接複製一份改檔名就好，不用另外生
- 已經有的 9 張：apple / cat / dog / fish / lion / pig / rabbit / tiger / fox
- `a cat` `a dog` `an apple` 三個片語已經複製好了（2026-08-09）
