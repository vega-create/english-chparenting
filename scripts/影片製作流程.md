# 課程影片製作流程（2026-08-11 定版）

240 課、每課一支影片。這份記錄**實測通過**的做法，以及一路上踩掉的坑。

```
角色設定圖 ─┐
            ├→ VideoExpress「Lipsync HD」→ Voice Changer → 下載 → AutoCut 串接
現有音檔 ───┘
```

---

## 一、為什麼是這條路

三條路都試過，只有這條同時滿足「嘴型準」和「聲音是我們的角色」：

| 做法 | 嘴型 | 聲音 | 結果 |
|---|---|---|---|
| `Narration Video (Choose my Audio)` | ❌ 不對嘴 | 你的音檔 | **會有兩個聲音**——影片模型自己也會配音，你的旁白是疊上去 |
| `Lipsync HD Video` | ✅ 準，支援雙角色 | ❌ 固定平台的 | 角色在影片跟網站是兩種聲音 |
| **`Lipsync HD` ＋ `Voice Changer`** | ✅ | ✅ | **採用**——Voice Changer 只換音色不動時間軸，嘴型維持正確 |

> **2026-08-11 A/B 實測**：平台自己配的聲音已經很接近 Finn，但 Vega 比對後說「還是有差距」，
> 所以 **Voice Changer 這一步保留、不省**。多一個 API 呼叫換角色聲音完全一致，划算。

> ⚠️ **不要把 ElevenLabs 或平台的聲音 clone 進 CloneVoice。**
> 那些聲音是授權「使用產出」、不是授權「再製聲音本身」。要投稿的專案不能有這種瑕疵。

---

## 二、量產前的一次性準備：Consistent Character

**這步不做，240 課會長出 240 種 Coco。**

1. 六隻角色的設定圖（16:9、白底、置中、全身）先傳進媒體庫的 `Images` 資料夾
2. `Create Video From Prompt` → 勾 **`Use Consistent Character`** → 出現 `Reference Photo 1 / 2` 兩個槽
3. 槽位用 **`Use from Library`** 從媒體庫挑角色 —— **不是**上傳、**不是**當場生
4. 兩個角色同框：Photo 1 放 Finn、Photo 2 放 Coco

> ⚠️ 走錯路會看到 **`UUID is empty.`**。我試過「直接上傳的圖」和「圖庫選的圖」按 `Consistent Character` 按鈕，
> 兩種都跳這個錯。正解是**先勾 `Use Consistent Character` 展開槽位，再從 library 挑進槽**。
> `Stylize Character` 那條路是繞遠路，不需要。

**接著就是每一課重複這兩步：**

```
寫 Image Prompt（該課的場景）→ Create Image   ← 角色鎖住、背景跟著課文換
            ↓
寫 Video Prompt（動作）+ 勾 Lipsync HD → Create Video → 填 Actor Script
```

---

## 三、操作步驟

1. **Create Video From Prompt** → 右上切 `Landscape 16:9` 或 `Vertical 9:16`
2. `Use from Library` 選角色圖（**必須先傳進 `Images` 資料夾**）
3. Video Prompt 描述場景與動作；多角色用「服裝＋actor 編號」指定誰是誰
4. **取消 `Share this in the public gallery`**（預設是打勾的）
5. 勾 `Lipsync HD Video` → `Create Video`
6. 跳出 `Create Lipsync Audio`：`Actor 1 Script` 填台詞，第二個角色按 `Add Actor 2`
7. 生好後在媒體庫雙擊該 clip → **`Voice Changer`** → `Choose Sample Audio` 選該角色的 ElevenLabs 音檔 → `Apply`
8. 再雙擊 → `Download`（或抓 `cdn-ny-b.videoexpress.ai/video/*.mp4`）
9. 丟進桌面 `AutoCut/素材夾input` → 分析 → 審核 → 出片

## 四、會卡住的地方（都踩過）

| 症狀 | 原因與解法 |
|---|---|
| 檔案選擇器看不到剛上傳的檔 | **只認資料夾裡的檔案**。先雙擊進 `Images`／`Audio` 再按 Upload file |
| 無法從本機上傳 | Chrome 工具擋自產檔案 → 走 R2 中轉（見下）|
| `Create Video` 按鈕不亮 | 要先有圖（`Create Image` 或 `Use from Library`）|
| 「Aspect ratio needs to be 9:16」 | 角色圖本身要是 9:16，不是只切換選項 |
| 生成的角色沒穿衣服／外型跑掉 | 參考圖用了臨時合成圖。**量產前先建 `Use Consistent Character`**，六隻各建一次 |
| 影片檔不見了 | 平台**只存 60 天**，生完立刻下載 |

**R2 中轉上傳**：素材先 `wrangler r2 object put` 到 `adventure-audio/tmp/...`，
再在頁面 `fetch` 回來塞進 `input[type=file]`。
bucket 的 CORS 只開 `GET/HEAD` 給那三個平台網域，設定見 `scripts/r2-cors.json`。

## 五、規格

- **圖**：半身以上、角色置中、16:9 或 9:16。全身太遠，lipsync 效果差
- **音檔**：單段上限 **10 秒**（videoScript 一句約 3–5 秒，剛好）
- **影片長度**：Advanced Mode 可手動指定 3–10 秒
- **兩種比例都留**：16:9 給課程頁與 YouTube、9:16 給 Shorts。`Outpainting` 可轉比例

## 六、腳本從哪來

`src/data/missions.ts` 的 **`videoScript`** 欄位，每課 4 句、共 912 句，直接填進 Actor Script。

- 這跟電子書的 `story` 是**兩份不同內容**：影片講該課重點、電子書用故事練
- ⚠️ **L1 M1–M12 這 12 課還沒有 `videoScript`**，要先補寫
- ⚠️ videoScript 目前**沒有任何錄音**，Voice Changer 需要的音色範本可沿用該角色現有的任一段 mp3

## 七、YouTube

影片做好、命名好、標題描述標籤產好 —— **但「發布」那一步由 Vega 自己按**。
公開發表不代按。要自動化就走 API 上傳成**私人草稿**，發布權仍在人手上。

## 八、內部 API（2026-08-11 挖到）

**沒有公開 API**（官網、文件、bundle 都沒有），但**有內部 API 可以打**，跟 aivideospeed 一樣。

確認到的端點：

```
POST /ai/api/generate_image_consistent_character   # 生場景圖（角色鎖定）
POST /ai/api/image2video                           # 生影片（Lipsync HD）
POST /ai/api/create_audio_voice_change             # 換音色（走 XHR，不是 fetch！）
     referenceAudioId=<音色範本的 media id>
     sourceAudioId=<要換聲音的影片 media id>
     startTime=0 & endTime=0
GET  /text_to_speech/languages_list
GET  /text_to_speech/voices/<locale>               # 例 en-US
GET  /voice_clone/languages_list
GET  /api/library/get_media/4?categoryId=...       # 讀媒體庫
```

Content-Type 是 `application/x-www-form-urlencoded`，例如 `prompt=<場景描述>&...`。

同源、靠 cookie 驗證，所以在已登入的分頁裡直接 `fetch` 就會過。

**怎麼挖剩下的端點**（影片生成、Voice Changer 等）：在頁面裝一個 fetch 攔截器，
然後手動觸發一次該功能，把它打的網址與參數錄下來。

```js
// 裝在 console 或 javascript_tool
localStorage.setItem('__log','[]');
const base = window.fetch;
window.fetch = function (u, opt) {
  const url = typeof u === 'string' ? u : (u && u.url) || '';
  if (/\/ai\/api\/|\/api\//.test(url)) {
    const a = JSON.parse(localStorage.getItem('__log') || '[]');
    a.push({ m: (opt && opt.method) || 'GET', u: url, b: opt && opt.body ? String(opt.body) : null });
    localStorage.setItem('__log', JSON.stringify(a.slice(-40)));
  }
  return base.apply(this, arguments);
};
```

> ⚠️ 攔截器只在該分頁存活，重新整理就沒了；而且 body 不要截斷，
> 不然會像我第一次那樣只看到 `prompt` 一個參數。

**三個主要端點都到齊了**，240 課可以腳本化。

> ⚠️ **Voice Changer 走 XHR 不是 fetch** —— 只掛 fetch 攔截器會什麼都錄不到，我卡了兩次。
> 攔截器要同時包 `XMLHttpRequest.prototype.open/send`。

`create_audio_voice_change` 的參數乾淨得出乎意料：**只要兩個 media id**。
所以六隻角色的音色範本各記一個 id，之後量產換聲音就是查表帶入。

### UI 上會卡住的最後一關

`Create Video` 按了沒反應，是因為**輪播裡要先點選一張圖**（右上角出現藍勾）才算選定。
沒選就按，按鈕不會有任何回應也不報錯。

## 九、內部 API 完整參數（2026-08-12 實測補齊，量產用）

三步全部可以在已登入分頁用 fetch 打，不用碰 UI：

```js
// 1) 生場景圖（角色鎖定）→ 回 uuid
POST /ai/api/generate_image_consistent_character
  prompt=<場景描述>&type=3d&mediaId=<Cc角色圖id>&aspect=16:9&generatorName=create_from_prompt

// 圖好了沒：HEAD https://s3.renderplatform.com/user-assets/preview/<uuid>.jpg 回 200 就是好了（約 40 秒）

// 2) 圖轉影片（Lipsync HD）→ 回 uuid
POST /ai/api/image2video
  type=3d&imagePrompt=<同上場景描述>&prompt=<Actor 描述>&uuid=<圖的uuid>&mediaId=0&audioMediaId=0
  &isShared=0&aspect=16:9&enhanceHumanFace=0&isTalkingVideoFromText=1&isNarrationVideo=0
  &enhanceVideoPrompt=1&videoOnly=0&speed=&generatorName=create_from_prompt
  &faceImageMediaId=0&faceSwap=0&mode=&speech1=<台詞>&speech2=

// 3) 換音色（已知，見第八節）：referenceAudioId + sourceAudioId

// 影片好了沒：GET /api/library/get_media/4?categoryId=<My AI Videos資料夾id>，
// 每個 media 物件有 uuid 欄位，對回 image2video 回傳的 uuid；mediaPath 就是下載網址
```
