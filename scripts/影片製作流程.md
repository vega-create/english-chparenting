# 課程影片製作流程（2026-08-11 定版）

240 課、每課一支影片。這份記錄**實測通過**的做法，以及一路上踩掉的坑。

```
角色設定圖 ─┐
            ├→ VideoExpress「Lipsync HD」→ Voice Changer → 下載 → AutoCut 串接
現有音檔 ───┘
```

---

## 一、為什麼是這條路

三條路都試過，只有這條同時滿足「嘴型準」和「聲音是我們的角色」：

| 做法 | 嘴型 | 聲音 | 結果 |
|---|---|---|---|
| `Narration Video (Choose my Audio)` | ❌ 不對嘴 | 你的音檔 | **會有兩個聲音**——影片模型自己也會配音，你的旁白是疊上去 |
| `Lipsync HD Video` | ✅ 準，支援雙角色 | ❌ 固定平台的 | 角色在影片跟網站是兩種聲音 |
| **`Lipsync HD` ＋ `Voice Changer`** | ✅ | ✅ | **採用**——Voice Changer 只換音色不動時間軸，嘴型維持正確 |

> ⚠️ **不要把 ElevenLabs 或平台的聲音 clone 進 CloneVoice。**
> 那些聲音是授權「使用產出」、不是授權「再製聲音本身」。要投稿的專案不能有這種瑕疵。

---

## 二、操作步驟

1. **Create Video From Prompt** → 右上切 `Landscape 16:9` 或 `Vertical 9:16`
2. `Use from Library` 選角色圖（**必須先傳進 `Images` 資料夾**）
3. Video Prompt 描述場景與動作；多角色用「服裝＋actor 編號」指定誰是誰
4. **取消 `Share this in the public gallery`**（預設是打勾的）
5. 勾 `Lipsync HD Video` → `Create Video`
6. 跳出 `Create Lipsync Audio`：`Actor 1 Script` 填台詞，第二個角色按 `Add Actor 2`
7. 生好後在媒體庫雙擊該 clip → **`Voice Changer`** → `Choose Sample Audio` 選該角色的 ElevenLabs 音檔 → `Apply`
8. 再雙擊 → `Download`（或抓 `cdn-ny-b.videoexpress.ai/video/*.mp4`）
9. 丟進桌面 `AutoCut/素材夾input` → 分析 → 審核 → 出片

## 三、會卡住的地方（都踩過）

| 症狀 | 原因與解法 |
|---|---|
| 檔案選擇器看不到剛上傳的檔 | **只認資料夾裡的檔案**。先雙擊進 `Images`／`Audio` 再按 Upload file |
| 無法從本機上傳 | Chrome 工具擋自產檔案 → 走 R2 中轉（見下）|
| `Create Video` 按鈕不亮 | 要先有圖（`Create Image` 或 `Use from Library`）|
| 「Aspect ratio needs to be 9:16」 | 角色圖本身要是 9:16，不是只切換選項 |
| 生成的角色沒穿衣服／外型跑掉 | 參考圖用了臨時合成圖。**量產前先建 `Use Consistent Character`**，六隻各建一次 |
| 影片檔不見了 | 平台**只存 60 天**，生完立刻下載 |

**R2 中轉上傳**：素材先 `wrangler r2 object put` 到 `adventure-audio/tmp/...`，
再在頁面 `fetch` 回來塞進 `input[type=file]`。
bucket 的 CORS 只開 `GET/HEAD` 給那三個平台網域，設定見 `scripts/r2-cors.json`。

## 四、規格

- **圖**：半身以上、角色置中、16:9 或 9:16。全身太遠，lipsync 效果差
- **音檔**：單段上限 **10 秒**（videoScript 一句約 3–5 秒，剛好）
- **影片長度**：Advanced Mode 可手動指定 3–10 秒
- **兩種比例都留**：16:9 給課程頁與 YouTube、9:16 給 Shorts。`Outpainting` 可轉比例

---

## 五、腳本從哪來

`src/data/missions.ts` 的 **`videoScript`** 欄位，每課 4 句、共 912 句，直接填進 Actor Script。

- 這跟電子書的 `story` 是**兩份不同內容**：影片講該課重點、電子書用故事練
- ⚠️ **L1 M1–M12 這 12 課還沒有 `videoScript`**，要先補寫
- ⚠️ videoScript 目前**沒有任何錄音**，Voice Changer 需要的音色範本可沿用該角色現有的任一段 mp3

---

## 六、YouTube

影片做好、命名好、標題描述標籤產好 —— **但「發布」那一步由 Vega 自己按**。
公開發表不代按。要自動化就走 API 上傳成**私人草稿**，發布權仍在人手上。
