## 四、短文本發音問題的完整解法（2026-08-13 實戰定版）

單字、單一字母這種超短文本，TTS 會自由發揮（kite 唸成日文、yoyo 唸成中文「有有」、W 唸成 Vision）。
**逐級升級的解法，寫進 gen 腳本的順序：**

1. **一般句子**：`eleven_multilingual_v2` 直接生，Scribe 驗（一次過率 ~90%）
2. **短單字**：改 `eleven_turbo_v2_5` + `language_code=en`（鎖英文），best-of-3 挑 STT 最像的
3. **單一字母／頑固字**：`eleven_turbo_v2` + **ARPAbet 音標鎖定**——這招幾乎全中：
   ```
   <phoneme alphabet="cmu-arpabet" ph="EY1">A</phoneme>
   A=EY1  B=B IY1  C=S IY1  D=D IY1  E=IY1  H=EY1 CH  M=EH1 M  N=EH1 N
   S=EH1 S  T=T IY1  U=Y UW1  V=V IY1  W=D AH1 B AH0 L Y UW0  Y=W AY1  Z=Z IY1
   van=V AE1 N  yoyo=Y OW1 Y OW2  an=AE1 N  hat=HH AE1 T  am=AE1 M  sun=S AH1 N
   ```
   ⚠️ 音標 tag 只有 turbo_v2 / flash_v2 / english_v1 支援，multilingual 不支援
4. **STT 的字典盲區**：audio 對但轉錄怪（ay ay → "Hey hey"、an → "And"），
   分數低不代表錯，**最終仍以 Vega 耳朵為準**

英文的驗收迴圈：STT 全驗 → 低分做聽審頁（`開我來聽.html` 樣式，勾 OK 回貼編號）→
Vega 標重生的照上面等級加碼 → 重複到清零。L1 全程三輪收斂。
