# 影片量產流程（2026-08-18 定版，L5/L6 實戰驗證）

每級 20 課 × 7 景 = 140 景。全流程：

1. **腳本**：自然生活對話 7 句/課（禁教學台詞），審稿頁給 Vega 過稿後寫入 missions.ts videoScript
2. **分鏡**：每景手寫 pose + act + 場景背景（jobs json：lvl/m/s/k/img/act/sp）
3. **泵**（scripts/videoexpress-pump.js 注入 VideoExpress 分頁）：
   - generate_image_consistent_character → image2video(speech1) → create_audio_voice_change → library 配對
   - 30 秒一 tick、每 tick 一件；佇列可隨時 push 追加
   - ⚠️ 分頁跑久會凍（fetch 全掛）：同步 JS 仍可撈狀態 → 開新分頁重注入續跑，一景不丟
4. **收成**（scripts/harvest_level.py，AE_LEVEL=n AE_JOBS=path 環境變數）：
   - 下載 VC → STT 逐景驗口白（<0.85 才人工判斷；笑聲/嘆氣/數字格式=誤報放行）
   - 壞景塞回泵重做（act 加明確指示，如 saying the line exactly once）
   - 串接（重編碼 crf18）→ mix_bgm4 公式混音（7 首輪替、IDX=((L-1)*20+M-1)%7、OFF=(L*53+M*37)%(td-75)、vol 0.12）
   - 上 R2 videos/L{n}/ → words.json 卡拉OK字幕（引號混用解析已修）
5. **上線**：missions.ts videoUrl 逐課補、commit push

錄音側：build_lesson_manifest.py → gen_lesson_audio.py → fix_flagged_audio.py（短字鎖語言剪接/大寫破縮寫/Yesterday 前綴救 -ed）
