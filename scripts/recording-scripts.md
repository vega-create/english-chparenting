# Adventure English 錄音腳本（真人錄音版）

## 🎙 錄音方法

**設備**：iPhone「語音備忘錄」或電腦麥克風即可
**環境**：安靜房間、嘴離麥克風 10-15 cm
**檔案格式**：m4a / mp3 / wav 都可以
**檔名**：依照下方標籤命名（例：`01-welcome.m4a`）

**錄音技巧：**
- 語氣自然，像跟小朋友講話一樣
- 不用太快，停頓自然
- 念錯了直接重來，不用剪輯
- 一段一個檔案
